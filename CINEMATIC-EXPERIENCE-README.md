# Digitalford Cinematic Experience Layer

Added progressive-enhancement effects across the existing website without changing its URLs or SEO copy.

## Included
- Raw WebGL liquid hero background with pointer response
- GSAP + ScrollTrigger motion via jsDelivr CDN
- Pinned horizontal-scrolling growth story on the homepage
- Scroll and pointer parallax
- Magnetic buttons and liquid button surface effects
- Fine-pointer custom interactive cursor
- Cinematic internal-page curtain transitions
- User-controlled synthesized interface sound (off by default)
- AI-themed live signal HUD in hero areas
- Existing 3D cards and long-form blog visual explainers retained
- Reduced-motion, touch-device, and WebGL-unavailable fallbacks

## Dependencies
GSAP and ScrollTrigger are loaded from jsDelivr. If they are unavailable, the website still works and falls back to native/CSS interactions. WebGL uses the browser's built-in WebGL implementation and does not require Three.js.

## Performance safeguards
- WebGL is disabled on narrow mobile screens and device-pixel-ratio is capped.
- Custom cursor and pointer-heavy parallax are disabled for coarse pointers.
- Motion is reduced when the OS/browser requests reduced motion.
- Sound requires an explicit user click and is muted by default.
