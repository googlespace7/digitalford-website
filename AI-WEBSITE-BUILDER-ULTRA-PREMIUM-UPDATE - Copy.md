# AI Website Builder — Ultra-Premium Multi-Page Upgrade

This build extends the existing Digitalford AI Website Builder without redesigning the rest of the website.

## What changed

- Automatically creates a richer 7–10 page website architecture when appropriate.
- Keeps Home, About, Products, Services, Gallery/Work, FAQ and Contact pages, plus category-specific pages such as Menu, Collections, Properties, Packages, Courses, Programs, Treatments, Capabilities, Expertise, Solutions or Work.
- Adds premium section systems: immersive/editorial heroes, trust strips, bento showcases, editorial spotlights, visual galleries, process sections, FAQs and conversion CTAs.
- Keeps every generated section editable in the existing visual editor.
- Keeps Add Page and extends manual page creation up to 16 pages.
- Adds premium section types to Add Section.
- Preserves page-level SEO editing for title, meta description and URL slug.
- Continues to use business-specific inferred products/services, editable sample pricing, realistic sample imagery and the editable starter logo.

## Content integrity

AI-generated prices remain sample/demo values until reviewed by the business. The generator avoids inventing awards, certifications, ratings, years in business or other unsupported authority claims.

## Deployment

No new third-party dependency is required. The existing optional PHP AI endpoint remains supported. Static hosting continues to use the local smart generator fallback.
