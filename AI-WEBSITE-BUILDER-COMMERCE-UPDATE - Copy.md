# AI Website Builder — Commerce & Customer Features

Added to generated websites:

- Enquiry Now for service cards
- Buy Now and Add to Cart for product cards
- Wishlist / Save for later
- Cart with quantity controls and order summary
- Customer sign-up/login preview
- Order history preview
- WhatsApp service enquiries and order handoff
- Floating WhatsApp action
- Editable Instagram, Facebook, YouTube and LinkedIn links
- Products + Cart and Services + Enquiry section presets in the visual editor

## Storage / deployment note

Cart, wishlist, preview account and order history use browser localStorage in this concept builder. Checkout does not charge a payment method. For production launch, connect a secure server-side authentication/order system and a payment gateway if online payment is required.
